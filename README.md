# जेनwin. — Oversized Streetwear & Custom DTG Prints E-Commerce Platform

A modern, high-performance, full-stack E-Commerce platform built with React, Vite, TailwindCSS, Express, and Firebase.

## 🚀 Features

- 🛍️ **Interactive Apparel Storefront**: Dynamic product catalog with category filtering, size/color selection, and instant search.
- 🎨 **Custom DTG T-Shirt Printing**: Real-time canvas printer tool with image upload, custom text, and placement previews.
- 🛒 **Cart & Checkout Engine**: Seamless cart drawer, coupon code validation, pincode lookup, and 1-click saved address auto-fill.
- ⚡ **Satellite Radar Order Tracking**: Realtime timeline tracking for placed, confirmed, shipped, and delivered packages.
- 👑 **Loyalty & Customer Dashboard**: VIP tier progress, order history, wishlist management, and non-blocking background reviews.
- 💼 **Admin & Employee Consoles**: Complete management suite for products, categories, stock, orders, coupons, ads, and store settings.
- 🌐 **Vercel & Firebase Ready**: Optimized for 1-click deployment on Vercel Serverless Functions and Firebase Hosting.

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, React Router v7, TailwindCSS, Lucide Icons
- **Backend API**: Node.js, Express (Serverless Compatible)
- **Database & Auth**: Firebase Realtime Database, Firebase Authentication
- **Deployment**: Vercel (`vercel.json`) & Firebase Hosting

## 💻 Local Setup

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Dev Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
